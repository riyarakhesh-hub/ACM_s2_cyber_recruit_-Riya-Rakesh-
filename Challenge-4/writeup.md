1. CHALLENGE DESCRIPTION
   Image recovered from an offline archaeological dataset shows an image of a structure. In the image, the structure shown doesnt cast a clear shadow even under direct sunlight. The given image has repeating stone stair geometry, no inscriptions, no visible water, no people, no sky. The given quote is "Built to defeat heat, not enemies." The challenge is to identify the structure and state in which it exists.
2. APPROACH/ ANALYSIS
   From visual confirmation only, my first assumption was this structure was Indian. So on searching in Google for "ancient indian structures with repeating stone stair geometry built to defeat heat". upon going through the search image i was able to find an image of the structure from a different angle. Upon reading the article, i was able to find the details of the structure. It is an ancient stepwell known as Dhabhai Kund built in the state of Rajasthan.
